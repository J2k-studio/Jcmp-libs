# The libraries of Jcmp-libs: how to use them

Each page has what the library is, an example that runs (with its output) and the list of its functions.

| library | what it is |
|---|---|
| [`<canvas>`](canvas.md) | drawing with characters, with a depth buffer |
| [`<complex>`](complex.md) | complex numbers |
| [`<deflate>`](deflate.md) | CRC-32, DEFLATE and gzip |
| [`<example>`](example.md) | example |
| [`<gamej>`](gamej.md) | Jaric Engine: a small game engine |
| [`<gpu>`](gpu.md) | the graphics chip through the Jaric app |
| [`<native>`](native.md) | call the libraries of the system |
| [`<neuron>`](neuron.md) | tensors and small neural networks that train on the phone |
| [`<opengl3>`](opengl3.md) | OpenGL ES 3.1 / 2.0 on the real driver |
| [`<png>`](png.md) | png |
| [`<quat>`](quat.md) | rotations in 3D (quaternions) |
| [`<screen>`](screen.md) | a picture of colour dots in the terminal |
| [`<simd>`](simd.md) | vectors of 2 or 4 numbers in one register (NEON) |
| [`<stats>`](stats.md) | numbers about a list of numbers |
| [`<vulkan>`](vulkan.md) | Vulkan on the real driver (first step) |
